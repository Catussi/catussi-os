## Recent hands-on experience

### Angular and TypeScript

I used them on ELVIR to build flows for young person, tutor, and administrator. I worked with Angular Material, forms, API consumption, session handling, responsive design, and loading or error states.

### FastAPI and Python

I built REST endpoints, validation schemas, JWT authentication, role-based permissions, and integration with external services. Python is also my main language for data analysis and machine learning.

### PostgreSQL and SQLAlchemy

I designed and maintained ELVIR's relational model, including users, sessions, and simulations. I managed schema changes with Alembic and used Supabase as a managed service.

### Git, Docker, and deployment

I use Git and GitHub to version, document, and review changes. I've prepared environments with Docker and Docker Compose, frontend on Vercel, and backend or data services on Northflank, Render, and Supabase.

### AI integrations

On ELVIR I connected LiveAvatar, LiveKit, and ElevenLabs. My experience is integrating these services into a product, giving them context, and managing their sessions — not building the proprietary models behind those platforms.

## Machine learning and data analysis

My background includes the IBM Data Science Professional Certificate and a capstone thesis in interpretable machine learning.

I've worked with:

- pandas and NumPy for data preparation and exploration;
- scikit-learn for classification, regression, clustering, and pipelines;
- SHAP to interpret predictions and analyze variable contributions;
- TensorFlow and Keras in academic neural network projects;
- Matplotlib, Seaborn, and Power BI for visualization;
- cross-validation, metric selection, and model comparison.

My most representative projects are the thesis on academic trajectories, the analysis of 79,000 CS:GO matches, and concrete strength prediction.
