# catussi-os

Portafolio interactivo de **Catalina Barria Otto (@Catussi)** — un escritorio completo en el navegador con apps, explorador de archivos, terminal y documentación integrada.

**Sitio:** [catussi.dev](https://catussi.dev/)  
**Repositorio:** [github.com/Catussi/catussi-os](https://github.com/Catussi/catussi-os)

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npx serve out -l 3010
```
